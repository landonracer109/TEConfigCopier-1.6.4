# Changelog

## 1.0.0 (2026-09-30)

First version.

- Copy a Thermal Expansion machine's side configuration, redstone mode, access, and a Tesseract's
  frequency and modes with paper and the copy key (C); paste with sneak + right-click.
- Sides are pasted relative to each machine's front.
- Only copies blocks the player can open, and only pastes access onto blocks the player owns.
- Client side only: works on servers that don't have it.
